# Signý Kristín

My personal website, built with [Astro](https://astro.build) and hosted on Cloudflare.

## Development

```sh
npm install
npm run dev
```

## Content

| What             | Where                           |
| ---------------- | ------------------------------- |
| Name, bio, links | `src/data/site.ts`              |
| Projects         | `src/content/projects/`         |
| Publications     | `src/content/publications.yaml` |
| Talks            | `src/content/talks.yaml`        |
| CV               | `src/data/cv.ts`                |
| Photo            | `src/assets/photo.*`            |
